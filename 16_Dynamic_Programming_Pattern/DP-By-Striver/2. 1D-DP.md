# DP — 1D Problems (Linear DP)

> **Quick Ref — Striver's 3 Steps**
> 1. Express the problem in terms of an **index**
> 2. Do **all possible things** at that index
> 3. **SUM** (count ways) / **MIN or MAX** (optimize) the results

> **Pattern signals:** `"number of ways"` → SUM &nbsp;|&nbsp; `"min/max cost"` → MIN/MAX &nbsp;|&nbsp; `"no two adjacent"` → Pick/Skip &nbsp;|&nbsp; `"circular array"` → 2 linear runs &nbsp;|&nbsp; `"at most k steps"` → loop j=1..k

## 1. Climbing Stairs

**Problem:** Given `n` steps, reach step `n` from step `0`. Each move can be 1 or 2 steps. Return the number of unique ways.

```
Input: n = 3      Output: 3
Ways: [1+1+1], [1+2], [2+1]
```

### Applying Striver's 3 Steps
```
STEP 1: f(n) = number of ways to reach step n

STEP 2: Choices at step n
        → came from step (n-1)  [1-step jump]
        → came from step (n-2)  [2-step jump]

STEP 3: "count of ways" → SUM
        f(n) = f(n-1) + f(n-2)
```

**Recurrence:** `f(n) = f(n-1) + f(n-2)` &nbsp;|&nbsp; Base: `f(0)=1, f(1)=1`

### ① Recursive
```java
public static int climbStairs(int n) {
    if (n == 0) return 1;
    if (n == 1) return 1;
    return climbStairs(n - 1) + climbStairs(n - 2);
}
```
⏱ O(2^N) | 💾 O(N)

### ② Memoization
```java
private int func(int n, int[] dp) {
    if (n <= 1) return 1;
    if (dp[n] != -1) return dp[n];
    return dp[n] = func(n-1, dp) + func(n-2, dp);
}
public int climbStairs(int n) {
    int[] dp = new int[n + 1];
    Arrays.fill(dp, -1);
    return func(n, dp);
}
```
⏱ O(N) | 💾 O(N)+O(N)

### ③ Tabulation
```java
public int climbStairs(int n) {
    int[] dp = new int[n + 1];
    dp[0] = 1; dp[1] = 1;
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i-1] + dp[i-2];
    return dp[n];
}
```
⏱ O(N) | 💾 O(N)

### ④ Space Optimized ✅
```java
public int climbStairs(int n) {
    int prev2 = 1, prev = 1;
    for (int i = 2; i <= n; i++) {
        int cur = prev + prev2;
        prev2 = prev;
        prev = cur;
    }
    return prev;
}
```
⏱ O(N) | 💾 **O(1)**

> 💡 Only the last 2 values are needed — this is Fibonacci in disguise.

## 2. Frog Jump

**Problem:** A frog is at step `0`. Given `heights[]`, cost to jump from step `i` to `j` = `abs(heights[i] - heights[j])`. Can jump 1 or 2 steps. Return minimum energy to reach step `n-1`.

```
Input: heights = [2,1,3,5,4]    Output: 2
Path: 0→2→4  →  abs(2-3) + abs(3-4) = 1+1 = 2
```

### Applying Striver's 3 Steps
```
STEP 1: f(i) = minimum energy to reach step i

STEP 2: Choices at step i
        → came from (i-1), cost = abs(h[i] - h[i-1])
        → came from (i-2), cost = abs(h[i] - h[i-2])

STEP 3: "minimum energy" → MIN
        f(i) = min(f(i-1) + cost1,  f(i-2) + cost2)
```

**Recurrence:**
```
dp[i] = min(dp[i-1] + abs(h[i]-h[i-1]),  dp[i-2] + abs(h[i]-h[i-2]))
Base: dp[0] = 0
```

### ① Recursive
```java
public int frogJump(int[] heights, int ind) {
    if (ind == 0) return 0;
    int jumpOne = frogJump(heights, ind-1) + Math.abs(heights[ind] - heights[ind-1]);
    int jumpTwo = Integer.MAX_VALUE;
    if (ind > 1)
        jumpTwo = frogJump(heights, ind-2) + Math.abs(heights[ind] - heights[ind-2]);
    return Math.min(jumpOne, jumpTwo);
}
```
⏱ O(2^N) | 💾 O(N)

### ② Memoization
```java
private int solve(int ind, int[] heights, int[] dp) {
    if (ind == 0) return 0;
    if (dp[ind] != -1) return dp[ind];
    int jumpOne = solve(ind-1, heights, dp) + Math.abs(heights[ind] - heights[ind-1]);
    int jumpTwo = Integer.MAX_VALUE;
    if (ind > 1)
        jumpTwo = solve(ind-2, heights, dp) + Math.abs(heights[ind] - heights[ind-2]);
    return dp[ind] = Math.min(jumpOne, jumpTwo);
}
```
⏱ O(N) | 💾 O(N)+O(N)

### ③ Tabulation
```java
public int frogJump(int[] heights) {
    int n = heights.length;
    int[] dp = new int[n];
    dp[0] = 0;
    for (int i = 1; i < n; i++) {
        int jumpOne = dp[i-1] + Math.abs(heights[i] - heights[i-1]);
        int jumpTwo = Integer.MAX_VALUE;
        if (i > 1)
            jumpTwo = dp[i-2] + Math.abs(heights[i] - heights[i-2]);
        dp[i] = Math.min(jumpOne, jumpTwo);
    }
    return dp[n-1];
}
```
⏱ O(N) | 💾 O(N)

### ④ Space Optimized ✅
```java
public int frogJump(int[] heights) {
    int n = heights.length;
    int prev = 0, prev2 = 0;
    for (int i = 1; i < n; i++) {
        int jumpOne = prev + Math.abs(heights[i] - heights[i-1]);
        int jumpTwo = Integer.MAX_VALUE;
        if (i > 1)
            jumpTwo = prev2 + Math.abs(heights[i] - heights[i-2]);
        int cur = Math.min(jumpOne, jumpTwo);
        prev2 = prev;
        prev = cur;
    }
    return prev;
}
```
⏱ O(N) | 💾 **O(1)**

> 💡 Same structure as Climbing Stairs — just replace SUM with MIN, and add a cost to each choice.

## 3. Frog Jump with K Distances

**Problem:** Same as Frog Jump but the frog can jump **1 to K steps** at a time. Return minimum energy to reach step `n-1`.

```
Input: heights = [10,5,20,0,15], k=2    Output: 15
Input: heights = [15,4,1,14,15], k=3    Output: 2
```

### Applying Striver's 3 Steps
```
STEP 1: f(i) = minimum energy to reach step i

STEP 2: Choices at step i — now a loop, not 2 hardcoded options
        → came from (i-1), (i-2), ..., (i-k)   [any j in 1..k]

STEP 3: "minimum energy" → MIN over all j
        f(i) = min over j in [1..k] of  f(i-j) + abs(h[i] - h[i-j])
```

**Recurrence:**
```
dp[i] = min { dp[i-j] + abs(h[i] - h[i-j]) }   for j = 1..k, if i-j >= 0
Base: dp[0] = 0
```

### ① Recursive
```java
private int func(int ind, int[] heights, int k) {
    if (ind == 0) return 0;
    int mmStep = Integer.MAX_VALUE;
    for (int j = 1; j <= k; j++) {
        if (ind - j >= 0) {
            int jump = func(ind-j, heights, k) + Math.abs(heights[ind] - heights[ind-j]);
            mmStep = Math.min(jump, mmStep);
        }
    }
    return mmStep;
}
```
⏱ O(k^N) | 💾 O(N)

### ② Memoization
```java
private int func(int ind, int[] heights, int k, int[] dp) {
    if (ind == 0) return 0;
    if (dp[ind] != -1) return dp[ind];
    int mmStep = Integer.MAX_VALUE;
    for (int j = 1; j <= k; j++) {
        if (ind - j >= 0) {
            int jump = func(ind-j, heights, k, dp) + Math.abs(heights[ind] - heights[ind-j]);
            mmStep = Math.min(jump, mmStep);
        }
    }
    return dp[ind] = mmStep;
}
```
⏱ O(N×k) | 💾 O(N)+O(N)

### ③ Tabulation
```java
public int frogJump(int[] heights, int k) {
    int n = heights.length;
    int[] dp = new int[n];
    dp[0] = 0;
    for (int i = 1; i < n; i++) {
        int mmSteps = Integer.MAX_VALUE;
        for (int j = 1; j <= k; j++) {
            if (i - j >= 0) {
                int jump = dp[i-j] + Math.abs(heights[i] - heights[i-j]);
                mmSteps = Math.min(jump, mmSteps);
            }
        }
        dp[i] = mmSteps;
    }
    return dp[n-1];
}
```
⏱ O(N×k) | 💾 O(N)

### ④ Space Optimized ✅ (Rolling Array)
```java
public int frogJump(int[] heights, int k) {
    int n = heights.length;
    int[] dp = new int[k];  // only keep last k values
    for (int i = 1; i < n; i++) {
        int mmSteps = Integer.MAX_VALUE;
        for (int j = 1; j <= k; j++) {
            if (i - j >= 0) {
                int jump = dp[(i-j) % k] + Math.abs(heights[i] - heights[i-j]);
                mmSteps = Math.min(mmSteps, jump);
            }
        }
        dp[i % k] = mmSteps;
    }
    return dp[(n-1) % k];
}
```
⏱ O(N×k) | 💾 **O(k)**

> 💡 Set K=2 and this becomes Problem 2 exactly. "At most K choices" always means — replace 2 hardcoded options with a `for j = 1 to k` loop.

## 4. Maximum Sum of Non-Adjacent Elements

**Problem:** Given array `nums`, return the maximum sum such that no two chosen elements are adjacent.

```
Input: nums = [2,1,4,9]    Output: 11   →  nums[0]+nums[3] = 2+9
Input: nums = [1,2,4]      Output: 5    →  nums[0]+nums[2] = 1+4
```

### Applying Striver's 3 Steps
```
STEP 1: f(i) = maximum sum from index 0 to i

STEP 2: Choices at index i
        → PICK   nums[i]:  add it, must skip (i-1), go to (i-2)
        → SKIP   nums[i]:  don't add it, carry forward f(i-1)

STEP 3: "maximum sum" → MAX
        f(i) = max( nums[i] + f(i-2),  f(i-1) )
```

**Recurrence:**
```
dp[i] = max(nums[i] + dp[i-2],  dp[i-1])
Base: dp[0] = nums[0]
```

### ① Recursive
```java
private int func(int ind, int[] arr) {
    if (ind == 0) return arr[0];
    if (ind < 0)  return 0;
    int pick    = arr[ind] + func(ind-2, arr);
    int nonPick = func(ind-1, arr);
    return Math.max(pick, nonPick);
}
```
⏱ O(2^N) | 💾 O(N)

### ② Memoization
```java
private int func(int ind, int[] arr, int[] dp) {
    if (ind == 0) return arr[0];
    if (ind < 0)  return 0;
    if (dp[ind] != -1) return dp[ind];
    int pick    = arr[ind] + func(ind-2, arr, dp);
    int nonPick = func(ind-1, arr, dp);
    return dp[ind] = Math.max(pick, nonPick);
}
```
⏱ O(N) | 💾 O(N)+O(N)

### ③ Tabulation
```java
public int nonAdjacent(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];
    for (int i = 1; i < n; i++) {
        int pick    = nums[i] + (i > 1 ? dp[i-2] : 0);
        int nonPick = dp[i-1];
        dp[i] = Math.max(pick, nonPick);
    }
    return dp[n-1];
}
```
⏱ O(N) | 💾 O(N)

### ④ Space Optimized ✅
```java
public int nonAdjacent(int[] nums) {
    int n = nums.length;
    int prev = nums[0], prev2 = 0;
    for (int i = 1; i < n; i++) {
        int pick    = nums[i] + (i > 1 ? prev2 : 0);
        int nonPick = prev;
        int cur = Math.max(pick, nonPick);
        prev2 = prev;
        prev = cur;
    }
    return prev;
}
```
⏱ O(N) | 💾 **O(1)**

> 💡 Binary choice at every index — take it (jump 2 back) or leave it (carry prev). House Robber is this problem on a circular array.

## 5. House Robber (Circular)

**Problem:** Same as Problem 4 but houses are in a **circle** — first and last house are adjacent. Return maximum loot without robbing two adjacent houses.

```
Input: money = [2,1,4,9]      Output: 10   →  money[1]+money[3] = 1+9
Input: money = [1,5,2,1,6]    Output: 11   →  money[1]+money[4] = 5+6
```

### Applying Striver's 3 Steps
```
STEP 1: f(i) = same as Problem 4

STEP 2: Choices at index i → same: PICK or SKIP

STEP 3: MAX — but circular constraint blocks picking both ends

KEY TRICK: You can never pick both house[0] and house[n-1].
           So split into 2 cases and run Problem 4 on each:

           Run 1 → [0 .. n-2]   exclude last house
           Run 2 → [1 .. n-1]   exclude first house
           Answer = max(Run1, Run2)
```

### ① Recursive
```java
private int func(int ind, int[] arr) {
    if (ind == 0) return arr[0];
    if (ind < 0)  return 0;
    int pick    = arr[ind] + func(ind-2, arr);
    int nonPick = func(ind-1, arr);
    return Math.max(pick, nonPick);
}
public int houseRobber(int[] money) {
    int n = money.length;
    if (n == 1) return money[0];
    int[] arr1 = Arrays.copyOfRange(money, 0, n-1);
    int[] arr2 = Arrays.copyOfRange(money, 1, n);
    return Math.max(func(arr1.length-1, arr1), func(arr2.length-1, arr2));
}
```
⏱ O(2^N) | 💾 O(N)

### ② Memoization
```java
private int func(int ind, int[] arr, int[] dp) {
    if (ind == 0) return arr[0];
    if (ind < 0)  return 0;
    if (dp[ind] != -1) return dp[ind];
    int pick    = arr[ind] + func(ind-2, arr, dp);
    int nonPick = func(ind-1, arr, dp);
    return dp[ind] = Math.max(pick, nonPick);
}
public int houseRobber(int[] money) {
    int n = money.length;
    if (n == 1) return money[0];
    int[] arr1 = Arrays.copyOfRange(money, 0, n-1);
    int[] arr2 = Arrays.copyOfRange(money, 1, n);
    int[] dp1 = new int[n]; Arrays.fill(dp1, -1);
    int[] dp2 = new int[n]; Arrays.fill(dp2, -1);
    return Math.max(func(arr1.length-1, arr1, dp1), func(arr2.length-1, arr2, dp2));
}
```
⏱ O(N) | 💾 O(N)

### ③ Tabulation
```java
private int func(int[] nums) {
    int n = nums.length;
    int[] dp = new int[n];
    dp[0] = nums[0];
    for (int i = 1; i < n; i++) {
        int pick    = nums[i] + (i > 1 ? dp[i-2] : 0);
        int nonPick = dp[i-1];
        dp[i] = Math.max(pick, nonPick);
    }
    return dp[n-1];
}
public int houseRobber(int[] money) {
    int n = money.length;
    if (n == 1) return money[0];
    return Math.max(func(Arrays.copyOfRange(money, 0, n-1)),
                    func(Arrays.copyOfRange(money, 1, n)));
}
```
⏱ O(N) | 💾 O(N)

### ④ Space Optimized ✅
```java
class Solution {
    public int houseRobber(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
        if (n == 1) return nums[0];
        return Math.max(solve(nums, 0, n-2), solve(nums, 1, n-1));
    }
    private int solve(int[] nums, int start, int end) {
        int prev = nums[start], prev2 = 0;
        for (int i = start + 1; i <= end; i++) {
            int pick    = nums[i] + (i > start + 1 ? prev2 : 0);
            int notPick = prev;
            int curr = Math.max(pick, notPick);
            prev2 = prev;
            prev = curr;
        }
        return prev;
    }
}
```
⏱ O(N) | 💾 **O(1)**

> 💡 `start/end` pointers avoid copying the array — saves O(N) extra space vs `Arrays.copyOfRange`.

## Summary

| # | Problem | Index def | Choices | Combine | Space-opt trick |
|---|---|---|---|---|---|
| 1 | Climbing Stairs | ways to reach step n | n-1, n-2 | SUM | 2 vars |
| 2 | Frog Jump | min energy at step i | i-1, i-2 + cost | MIN | 2 vars |
| 3 | Frog Jump K | min energy at step i | i-1 .. i-k + cost | MIN | rolling array size k |
| 4 | Max Non-Adjacent | max sum at index i | pick / skip | MAX | 2 vars |
| 5 | House Robber | max sum, circular | pick / skip | MAX | run #4 twice w/ pointers |
